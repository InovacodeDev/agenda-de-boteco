# Changelog 0.0.7 (alfa)

- Login passa a bloquear duplo clique nos botões de envio e verificação de código
- Reenvio de código por e-mail mostra contagem regressiva e avisa quando o limite de envios por hora foi atingido
- Botão de favoritar evento e estabelecimento protegido contra clique duplo acidental
- Feed passa a mostrar eventos de todos os bares, mesmo os que ainda não apareceram na lista
- Favoritos mostram todos os eventos e bares salvos
- Busca de bares por nome consulta todo o catálogo, não só os bares já carregados
- Reenvio de código na exclusão de conta ganha contagem regressiva
- Política de Privacidade explica as avaliações e a exclusão de conta pelo próprio site
