# Changelog 0.0.4 (alfa)

- Agenda de eventos do painel carrega aos poucos conforme você rola a tela
- Contagem de favoritos por evento na tela de Métricas agora considera todos os eventos do seu bar, não só os mais recentes
- Nova página de Política de Privacidade, explicando o uso dos dados da conta e do estabelecimento
- Métricas, Avaliações e Configurações liberadas para todos os donos de bar no menu e no dashboard
- Botão "Cadastrar primeiro evento" do dashboard leva direto ao formulário de novo evento
