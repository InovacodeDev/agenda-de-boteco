# Changelog 1.0.4 (alfa)

- Sistema de avaliações para estabelecimentos com cálculo de média e distribuição de notas
- Correção no filtro de distância para garantir que todos os estabelecimentos cadastrados apareçam no catálogo
- Métricas do painel do dono passam a mostrar todos os eventos, carregados aos poucos
- Dono de bar passa a poder enviar o banner dos próprios eventos
- Envio de arquivo em formato não suportado mostra mensagem clara em vez de erro genérico
